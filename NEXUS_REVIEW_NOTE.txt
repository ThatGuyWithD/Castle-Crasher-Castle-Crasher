Nexus Mods Quarantine Review Note - Crasher Unlocker V1.2
==========================================================

Crasher Unlocker V1.2 is an offline, open-source Castle Crashers save editor written in C#/.NET Framework.

The program does NOT:
- inject DLLs or code into Castle Crashers;
- use WriteProcessMemory / CreateRemoteThread or similar process-injection APIs;
- connect to the internet;
- download or execute remote payloads;
- install services, scheduled tasks, startup entries, or other persistence;
- edit other players' save files.

The program DOES:
- locate the user's local Steam Castle Crashers save path, including reading standard Steam registry install-path values;
- check whether castle.exe is currently running so the program can refuse unsafe save writes while the game is open;
- decrypt and re-encrypt the local cc_save.dat using the save format's Blowfish-based encryption;
- validate/rebuild the save checksum;
- create, restore, and delete user-requested local backup files;
- open Windows Explorer for the save/backup folder;
- call uxtheme.dll and dwmapi.dll only for dark/light Windows UI theming.

Some antivirus engines currently label the executable with generic/ML/GameHack-style detections. The full source code and standard Microsoft C# build script are provided for review. No packer or obfuscator is used.

Current release: Crasher Unlocker V1.2
Assembly/file version: 1.2.0.0

Author note:
Profile Unlocks affect only the user's own local Castle Crashers save/profile. They do not grant items to other multiplayer users and do not require server/host ownership.
